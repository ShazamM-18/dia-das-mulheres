# Dia das Mulheres | Cartão interativo

Pequena experiência web comemorativa criada para o Dia das Mulheres. A página apresenta uma surpresa com interação envolvendo corações e uma mensagem de homenagem.

## Tecnologias
HTML, CSS e JavaScript em uma página web.

## Como visualizar
Abra o arquivo `index.html` em um navegador moderno ou clone o repositório com `git clone https://github.com/ShazamM-18/dia-das-mulheres.git`.

## Objetivo
Projeto pessoal de criatividade e experimentação com interações no navegador. Não requer backend.
